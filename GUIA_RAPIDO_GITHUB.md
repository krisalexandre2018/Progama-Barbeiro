# ⚡ Guia Rápido - Hospedar Política no GitHub (5 Passos)

## 🎯 Objetivo
Hospedar `privacy-policy.html` no GitHub Pages para obter URL pública.

---

## 📋 PASSO A PASSO VISUAL

### ✅ PASSO 1: Criar Conta no GitHub (2 min)

1. Acesse: **https://github.com/**
2. Clique: **"Sign up"**
3. Preencha:
   - Email: `kris.alexandre2018@gmail.com`
   - Password: [crie uma senha]
   - Username: [escolha um, ex: `ricardosidney`]
4. Verifique email
5. Faça login

---

### ✅ PASSO 2: Criar Repositório (1 min)

1. Clique no **"+"** (canto superior direito)
2. Clique: **"New repository"**
3. Preencha:
   ```
   Repository name: app-privacy-policy
   Description: Política de Privacidade - App Ricardo Sidney Barbeiro
   ```
4. Marque: **✅ Public** (obrigatório!)
5. Marque: **✅ Add a README file**
6. Clique: **"Create repository"**

---

### ✅ PASSO 3: Upload do Arquivo (2 min)

1. No repositório, clique: **"Add file" > "Upload files"**
2. Arraste ou selecione:
   ```
   E:\Todos os projetos\Progama Barbeiro\privacy-policy.html
   ```
3. No campo de commit, escreva:
   ```
   Adiciona política de privacidade
   ```
4. Clique: **"Commit changes"**

---

### ✅ PASSO 4: Ativar GitHub Pages (2 min)

1. Clique na aba: **"Settings"** (⚙️)
2. Menu lateral esquerdo: Clique em **"Pages"**
3. Em "Source", configure:
   ```
   Branch: main
   Folder: / (root)
   ```
4. Clique: **"Save"**
5. **AGUARDE 1-2 MINUTOS**
6. Atualize a página

Você verá:
```
✅ Your site is live at https://SEU-USUARIO.github.io/app-privacy-policy/
```

---

### ✅ PASSO 5: Obter e Testar URL (1 min)

**Sua URL final será:**
```
https://SEU-USUARIO.github.io/app-privacy-policy/privacy-policy.html
```

**Exemplo** (se username for `ricardosidney`):
```
https://ricardosidney.github.io/app-privacy-policy/privacy-policy.html
```

**TESTE:**
1. Abra a URL no navegador
2. Verifique se a política carregou
3. Confirme que o email aparece: `kris.alexandre2018@gmail.com`

---

## ✅ PRONTO!

Você tem a URL pública da política! 🎉

**COPIE E GUARDE ESSA URL** - Você vai usar na Play Console!

## 📱 Usar na Play Console

Quando estiver na Play Console:

1. Seção: **"Store listing"**
2. Campo: **"Privacy Policy URL"**
3. Cole a URL: `https://SEU-USUARIO.github.io/app-privacy-policy/privacy-policy.html`
4. Save

## 🆘 Se Tiver Problema

**404 - Página não encontrada:**
- Aguarde mais 2-3 minutos
- Limpe cache: Ctrl + F5
- Verifique se o arquivo é `privacy-policy.html` (nome exato)

**GitHub Pages não aparece:**
- Repositório DEVE ser Public
- Deve ter pelo menos 1 arquivo
- Tente trocar Branch para `main` e salvar novamente
